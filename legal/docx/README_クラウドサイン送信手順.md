## 送信の単位（案）

クラウドサインは1件の送信に複数ファイルを添付できます。相手ごとにまとめると4件になります。

1. **グロービス宛**：01、02、04、07、08。押印欄は02に2か所、07・08に各1か所。
2. **DBC宛**：01、03、04、09。押印欄は03と09に各1か所。
3. **Future Identity Capital宛**：04、06。押印欄は06に1か所。
4. **森山穂貴（自社）**：04、05、10。自分宛に送るか、Wordで押印してPDF保存する。

01と04は通知・提案であり相手の署名は不要なので、参考書類として添付します。送信者側の押印欄（発行会社・経営株主）は、クラウドサインの送信者押印機能で押すか、空欄のままでも差し支えありません。

## クラウドサインでの操作

1. Wordファイルをそのままアップロードする（自動でPDFに変換される）。事前にWordで「PDFとして保存」して体裁を確認してから、そのPDFをアップロードするとより確実。
2. 宛先を設定し、各承認書・同意書の四角い押印欄に「押印」の入力項目を置く。日付は本文に固定済みなので入力項目は不要。
3. 送信順は問わないが、株主間契約上の承認（02）は株主総会決議（同意書）より前が原則。同日付にしているので、グロービス宛の1件にまとめて送れば問題ない。
4. 締結後、合意締結証明書付きのPDFをダウンロードし、提案書・同意書・議事録を本店に10年間備え置く（会社法318条2項、319条2項。電磁的記録での備置可）。
5. 全員の同意書が揃った日を議事録の決議日にする。9月24日に揃わなかった場合は、10の日付を実際の到達日に直す。

## 締結後にやること

- 子会社の定款作成・認証、出資金の払込、設立登記（森山穂貴の就任承諾書を添付）。
- 子会社側でも設立後に会社法356条1項1号の競業承認を取る（株主は発行会社なので、発行会社代表取締役名の同意書を子会社の議事録に残す）。
- 株主間契約 第2.2条5項に準じ、子会社の登記事項証明書と更新した組織図を各投資者に共有する。
